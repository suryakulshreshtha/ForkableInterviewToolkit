## The seven-part format

| Part | What it's for |
|---|---|
| **1. Direct Answer** | The full, correct explanation |
| **2. Real-Time Project Example** | Grounds it in something that actually happened |
| **3. Coding / Practical Example** | Runnable code, not pseudocode |
| **4. STAR Answer** | For behaviour-flavoured questions |
| **5. Interview-Ready Answer** | The ~30-second spoken version — memorise this one |
| **6. Important Interview Point** | The trap, nuance, or overclaim to avoid |
| **7. One-Line Revision** | ⚡ The single line you skim on the train |
