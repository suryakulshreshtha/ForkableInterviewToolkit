# 10. Quick-Reference Glossary

One line per topic — the last thing to skim before you walk in.

---

| Topic | One-Line Summary |
| --- | --- |
| Pytest | Python's test runner/framework; fixtures, parametrize, and marks drive most Python automation. |
| Playwright (Python) | Auto-waiting, actionability-checked UI automation across Chromium/Firefox/WebKit via one API. |
| Locust | Python-native load testing; @task-decorated user classes replace JMeter's GUI thread groups. |
| pytest-bdd / behave | Gherkin .feature files bound to plain Python step functions, run through pytest. |
| GitHub Actions | YAML-defined CI/CD pipelines; installs deps, runs pytest, publishes reports on every push/PR. |
| Allure / pytest-html | Rich (Allure) or lightweight (pytest-html) HTML test reports with history and filtering. |
| Playwright Trace Viewer | Step-by-step replay of a failed test with DOM snapshots, network calls, and console logs. |
| venv / Poetry | Isolated, reproducible Python environments and pinned dependencies for the framework. |
| JMeter Threads | Virtual users; Thread Group controls ramp-up time and concurrent-user handling (tool-agnostic knowledge). |
| Jenkins | CRON-based scheduling, scheduled regression runs, and CI/CD execution — still common alongside GitHub Actions. |
| QA Fundamentals | Smoke, sanity, regression, usability, defect triage, and risk-based testing. |
